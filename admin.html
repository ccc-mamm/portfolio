连接 GitHub 并发布

你的访客只会看到作品集，管理后台需要拥有仓库写入权限的令牌。

第一步：填写仓库信息

Token 仅保存在此浏览器的当前标签页会话中，不写入网站源码或仓库。请创建只允许访问该仓库、具有 Contents: Read and write 权限的 Fine-grained Token。不要填写 GitHub 登录密码。

第二步：预览与发布

发布会把新图片写入 assets/uploads/，把项目内容写入 data/site.json。网站维持原有模板样式。

公开网站部署至 GitHub Pages 后，可通过 查看站点 ↗ 检查发布效果。提交后 GitHub Pages 可能需要短暂构建时间。若发生部分上传失败，请在保持当前页面打开的情况下重新发布。
